Issue #10：统一文档表示

由 Plan 派生的流程示意。

Source / Binding → Scrapy 下载 → 原文归档 → Recipe 回调 → 有界线程内五节点解析 → 校验与文档版本 → 可选业务输出入 Pipeline → Record

同一种表示节点

article · image · table · json · document_ref。空 HTML 可没有子节点；DOCX 正文在表格前后保留顺序，无法无损往返的 JSON 小数明确失败。格式优先按响应 MIME 判定，HTML 按声明字符集解码；引用遵循页面 base URL 并指向同类型目标身份，未成功解析时明确为 pending。身份由 Source、namespace、URL、方法及 POST 请求体摘要确定。

证据链

文档版本 → Snapshot / Observation → 原文 hash → Archive；业务 Record 另关联实际文档版本和原有字段 Locator。

验收

隔离 loopback 与 PostgreSQL，使用 CLI 验证真实采集、保存、查询、导出、业务衔接和零网络 Replay。
