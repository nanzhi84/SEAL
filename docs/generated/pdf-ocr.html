整份无文字 PDF OCR

唯一 Plan 与完整合同 · Issue #25

① HTTP 下载一次 → 原始 bytes / SHA-256 → MinIO CAS

② 异步等待同主机共享工作目录的 flock 名额（跨 Run 最多 4）→ 每份 PDF 一个隔离子进程

③ 子进程预检：任意页有文字 → native；整份无文字 → PDFium + 多语言 Tesseract

④ 每页文字 → 共用 SDK HTML → 页数、页码、格式与大小校验

⑤ PDFPage / PDFProcessResult → 既有 scraper → CrawlResult / Markdown

⑥ 既有结果归档 → Observation / Version → Snapshot → Results API / 原件附件

有界执行

执行期限取 OCR 独立时限与采集剩余预算较早值。超时、取消、退出统一终止进程组、回收进程、删除目录，最后释放名额。清理失败封闭管理器，拒绝迟到结果。

范围
