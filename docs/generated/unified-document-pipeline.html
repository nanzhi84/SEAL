SEAL · Document-only

来源发现与内容解析解耦，所有内容响应使用同一个文档保存入口。

Source YAML→Recipe / Binding / Run→Scrapy→Archive→Parser→Document Version→SQL / COPY

唯一内容产物

article · image · table · json · document_ref。列表、详情、附件、API 都经过 Archive → Parse → 保存。损坏文件和扫描 PDF 保留原文与明确错误，继续发现链接。

四个命令

seal init 显式迁移；seal collect source.yaml 自动绑定并采集；seal recheck source.yaml 在线检查变化；seal worker 消费持久任务并恢复。执行命令可用 --enqueue。

TTY 在 stderr 显示实时面板，stdout 始终单份 JSON。Known URL progress 仅表示当前已知集合。

版本与血缘

Document → Raw Revision → Version → Run Emission → Observation / Snapshot → Archive。相同 bytes 与规则复用 Version，每个 Run 保留独立证据；成功 Run 推进当前指针。

显式破坏性升级

删除 Record 专属表与旧结果实现；保留自建对象迁入 seal，去掉 seal_ 前缀。Procrastinate 保持原位置与名称。已有库先检查对象和行数，停 Worker、备份，再显式确认。回滚依赖备份恢复。

验收链路

CLI Collect → SQL / Archive / Document → Recheck → COPY。隔离 PG 与 HTTP 样本覆盖九种格式、迁移、版本、Worker、并发恢复和 TTY。样本通过不代表全站完整，生产迁移需要单独授权。
