持续发现与恢复

发现

每轮重新访问 Source 入口，Crawl4AI 递归发现链接。永久 Resource 清单保留，新轮 visited 重建。

恢复

恢复当前轮 checkpoint。Source 始终只有一个逻辑 Frontier，首版只允许一个活动执行者。

复查

批量获取到期 Resource，不依赖旧资源仍在导航中。SEAL 保存检查时间，长期 Frontier 与当前轮 SDK checkpoint 分离。

robots 采用 Protego 最长 Allow/Disallow 匹配，政策与业务请求使用同一 Source 身份；403 政策仍拒绝。SDK 错误分类排除源码上下文。归档成功后提交引用，run/URL 重复交付幂等。Source 会话锁和 epoch/generation 保护版本。SDK 0.9.4 checkpoint 会遗漏当前层未交付 URL；SEAL 把这些 URL 补回 SDK pending，崩溃允许重复网络请求，提交不重复。
