不拆段落、表格行/格或 JSON 字段；没有 group/data。根下内容有序，附件目标仍是同一种文档。共享引用不复制目标。

身份与实际版本

沿用 Source / namespace / URL 的 seal_document 身份与原文 Revision。新增不可变解析版本和 Run emission，保留 Snapshot、Observation、Binding、RecipeVersion 及解析代码/依赖/options。

同原文、不同解析规则仍可区分。Record 的 document_versions 保留所有实际输入；document Locator 从原文重建文档并复算，再执行 #6 映射与规范化。

引用不等于成功下载

保存引用前创建或核对同 Source / namespace 的目标身份。查询时区分 not_fetched、parse_failed、parsed，标记 state_scope: query_time。parsed 可指有效 staged 版本，不能据此推断目标 Run 已 complete。URL 与外键不对应、跨 Source 伪造引用拒绝。

独立 inspect/export 显示这些差别。只在 complete 在线 Run 推进当前视图；失败保留原文与已保存工件，Replay 不推进在线状态。

确定性解析

parse_document(snapshot, body, *, options=None) 返回 format/children，不联网。options 仅 body_css、title_css、format、csv_delimiter；保存层从冻结输入复算，Schema 合法不足以接受伪造内容。

HTML 图片只存 URL；DOCX/PDF 内嵌图片指向原容器 hash 与成员。全文 article 只有一个，正文清理/布局简化允许信息损失，原文保留。输入/ZIP 展开上限 64 MiB，表格共 500,000 格。

失败与历史兼容

下载、归档、解析、结构/引用与业务 Schema 失败进入既有 Run errors。已成功保存文档可按失败 Run 查询，不能覆盖旧成功指针。

0008 新增版本、emission、引用及当前版本外键，历史 Record / generic 导出与 hash 保留。升级重 pack、建 Binding，旧归档可零网络重处理；旧 document Locator 在 parser digest 变化时明确拒绝，精确旧执行需要配套旧环境与 DB。
