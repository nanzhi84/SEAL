同次输入、发现与故障恢复

同次解析

HTTP 在字符解码前计算指纹；PDF 的同次 bytes 暂存到 work，交给 SDK PDF scraper，不再次请求。unsupported 附件仍归档完整文件。

发现与复查

collect 每轮重访入口并重建 visited；recheck 按到期已知资源复查，即便已从导航消失。robots/范围/网络预算保持。

取消与恢复

Source 会话锁、epoch/generation 保护提交。checkpoint 补 SDK 未交付 URL 和已取得附件引用；Ctrl+C 退出130，恢复同 Run 按资源交付幂等。

浏览器仍为独立 headless Chromium，无用户登录状态；rendered_dom 不独立归档。未扩展浏览器下载触发交互，原始附件使用现有 HTTP 资源路径。无 Office/OCR 或新增 HTTP API；whole-site 始终 UNKNOWN。

四命令与消费合同

seal init [--backup PATH] · seal collect source.yaml · seal recheck source.yaml · seal worker --once。stdout 单份 JSON；collect/recheck 保持 receipt.v3。来源配置使用地图 dd-xxx。

下游查询 seal.current_resource_version、seal.version 或按 cursor 排序的 seal.version_delta，再用 Objects().json(result_ref) 与 deserialize_result 重建。观察列表从 Observation.result_ref 读取本轮结果；原始附件从 archive_ref、Observation.attachment_refs 或结果封装 attachment_refs / downloaded_files 取得。

SEAL_DATABASE_URL 与 SEAL_S3_ENDPOINT/BUCKET/ACCESS_KEY/SECRET_KEY 通过环境传入；SEAL_S3_REGION 默认 us-east-1。SEAL_WORK_DIR 控制临时文件。根 minio/ 仅服务管理，应用统一走 S3 API；验收用独立 work/artifacts 服务。

空库 schema 升级

新增 0012_minimal_archive.sql，允许文本 body_hash 非空而 archive_ref 为空；附件引用必须对应同次输入指纹。已登记 SQL checksum 不变。新库沿 ledger 初始化至0012；空旧内容库停客户端后执行 seal init --backup PATH，重复初始化不重复迁移。

没有旧内容兼容要求，不回填结果、不迁移旧对象或保留旧 timeline。非空旧内容库明确拒绝升级；旧 result_migration 与 archive_import 内部路径已删除。回滚须恢复升级前备份并使用配套旧代码。本 PR 不操作已有本地和生产服务。
