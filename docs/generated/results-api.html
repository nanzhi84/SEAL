公开字段白名单 / 类型
url / markdownResource URL / 原始 raw_markdown 字符串；无正文时为空字符串
metadatatitle、author、description、keywords：字符串或 null
linksinternal / external 数组；各项 href、text、title：字符串或 null
mediaimages / videos / audios 数组；src、alt、desc、type、format：字符串或 null；width：非负整数或 null
tablesheaders：字符串数组；rows：字符串二维数组；caption、summary：字符串或 null
attachments仅外层 attachment_refs；url 为服务地址；现有归档无可靠名称和 MIME，name / media_type 为 null

空集合为 []；未知字段移除，白名单类型不合法则整页报 archive_invalid。媒体数字字符串宽度显式转换为整数。网页中的未下载文件链接仅存在于正文或链接。

附件原始字节

Fernet 认证加密 ID 绑定来源、版本和附件位置，有效期24小时。下载重新验证当前来源许可、SQL归属、结果信封和对象哈希；旧版本附件仍可按令牌下载。

固定 application/octet-stream 和通用安全文件名；不推断类型、不物化磁盘副本。服务使用配置的公开基址，忽略 Host 和转发头。

有界资源

默认4个工作线程，上限8；每次顺序读取对象，等候槽位1秒。HTTP默认30秒，上限60秒；取消后的实际线程仍占用槽位。同期限到达时按阶段返回 server_busy 或 request_timeout。

结果对象16 MiB、附件50 MiB、页64 MiB；超限明确报错。数据库连接5秒/语句15秒；S3连接3秒/读取10秒/最多2次，按块读取并关闭 Body。
