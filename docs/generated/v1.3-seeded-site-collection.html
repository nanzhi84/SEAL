Review 后的冻结边界与证据

机制实际合同
Recheck仅调度冻结目标和 Runtime robots 政策；不扩展 Sitemap、页面链接、iframe 或隐式附件。直接列入计划的附件可解析。
partial Replay复算归档输入；精确匹配原拒绝证据，保留预算等原因和 partial 状态。未知请求或丢失的成功输入仍严格失败，零网络补齐。
Sitemap同一 robots 政策版本每 Crawl 主动发现一次，保留政策父输入；gzip 受冻结 Source 的解压大小上限约束，下载表示先归档。
政策与附件审计区分规则拒绝、政策 HTTP 拒绝和政策不可用。动态附件按 Content-Type 确认并保留父证据；XLSX 保存原文并明确 unsupported。
