API 对外接口

GET /sources 发现获授权的冻结入口；GET /results 读取固定版本并以 Link 翻页；GET /attachments/{attachment_id} 返回原始附件。三个接口均需 Bearer 认证，无发布指针返回503。当前许可每请求重读，旧分页及附件在期限内保留原快照。

一致性与不可变性

单一事务冻结来源及版本；复合外键验证来源、资源与版本归属。sealed 后快照和映射不可变。发布行锁与切换日志共享事务；无效 ID 或坏对象失败不动指针。Snapshot 不代表质量合格。

发布原始附件验证上限128 MiB，与采集可配置上限一致；API默认50 MiB，大附件需显式调高调用预算。
