跑通 ≠ 解析正确 ≠ 批准发布

例如把“更新日期”当作“发布日期”。 日期格式可能合法，定位也可能匹配原文。 这些技术校验仍不能证明字段的业务含义正确。

报告与导出标记 quality_status=not_evaluated。候选运行不会自动改变默认 Binding，但会进入运行历史。默认导出也可能包含候选结果，不能当作正式发布接口。

Locator 支持 date_iso 日期规范化及 segments.separator 拼接，保留定位并从归档原文复算最终值；旧 locator 保持兼容。自动 robots 请求关闭，业务 HTTP 错误、域名/路径与基本非公网地址限制继续生效。

complete 只代表技术完成；partial 保留有效结果；not_evaluated 不代表质量已通过。

归档失败、Schema 错误、超时和过期任务仍会被处理。删除 Trial 不等于放弃技术校验或并发控制。
