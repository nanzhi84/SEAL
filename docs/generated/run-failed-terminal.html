具体原因读取 errors 错误码数组。无重复 termination / terminal_reason；Scrapy finish_reason 保留原始执行上下文。complete 不代表全量覆盖或业务质量通过。

一次失败的边界

  • 临时故障在次数与总期限内 retryable；耗尽后 failed，具体耗尽码进入 errors 与未知覆盖证据。
  • 单次采集时间预算耗尽使用 crawl_time_budget_exceeded；保留原生 finish_reason，合法结果仍可显式导出。
  • generation / run_seq / attempt_epoch 继续隔离旧写入。
  • 只有 complete 推进成功基线；failed 有效产物可显式 export --run。
  • 默认成功视图保留历史成功结果；每条导出验证归档可读性与输入血缘。
